# 定点帧同步接入指南

面向在 AbilityKit 上做帧同步(frame-sync / lockstep)玩法的接入方。回答三个问题:
数值栈分几层、边界在哪、新增数值字段时的 checklist。
状态截至 2026-08(P0–P3 完成、bridge 已收敛,见文末路线图)。

## 1. 数值确定性栈(分层)

| 层 | 内容 | 谁用 |
|----|------|------|
| `com.abilitykit.deterministic` | `Fixed64`(Q32.32, raw long)、`FixedVec2/3`、`DeterministicMath`(Sqrt/三角/Clamp…)、`DeterministicRandom`、`DeterministicHash` | 一切确定性运算的内核,不依赖任何 AbilityKit 包 |
| `com.abilitykit.core` | `MathUtil.Sqrt` 已路由到定点实现 → 全仓库 `Vec2/Vec3.Magnitude / .Normalized / .Distance`、`Quat.LookRotation` 自动确定;公开的 `DeterministicMathBridge` 是 float 边界唯一桥(成员见 §2) | 所有包 |
| 战斗栈 | collision 的 sqrt/归一化点、motion 的轨迹/墙滑、projectile 运动学(Q32.32 内核 + float 公开 API)、`FrameTime` 定点累加 | combat.* / world.framesync |
| demo 玩法层 | MOBA 伤害/治疗/护盾/资源管线全定点(`MobaResourceFixedConvert` 边界) | demo.moba |

**原理**:IEEE 基本运算(加减乘除/比较)本身跨平台位一致,无需定点;
漂移源只有 sqrt/归一化/三角/三角函数依赖的累积——这些必须走定点内核。

## 2. 边界规则(铁律)

1. **模拟内部一律 `Fixed64`/`FixedVec3`**;float 只允许出现在三个边界,且单次换算:
   - **配置入口**:表/JSON 的 float 参数在 PlanAction/Schema/MO 构造处一次 `ToFixed`;
   - **表现出口**:事件、快照、诊断、HUD、IO 出口一次 `ToSingle`;
   - **公开 API 兼容层**:如 collision/projectile 的 float 签名内部立即转定点。
2. **换算用 `Fixed64.FromSingle`**(经 double 精确换算):同一份 float 位模式 → 同一 raw long。
   非有限值先归零(参照 `MobaResourceFixedConvert.ToFixed`),因为 `FromSingle` 对 NaN/Inf 抛异常。
3. **不要在模拟中途来回换算**——每次 float↔fixed 往返都是一次舍入点。

## 3. 回滚快照约定(raw long 约定)

定点字段进回滚/网络快照时**存 raw long,不存 float**(先例:projectile v7、ActorHp v2、
Shield v2、FrameTime v2):

```csharp
[MemoryPackOrder(n)] public readonly long ValueRaw;   // 序列化 Fixed64.RawValue
// 恢复:Fixed64.FromRaw(entry.ValueRaw)
```

理由:float 边界会丢低 32 位,不能用于位断言;raw long 往返无损。
payload 带 `Version` 字段,Import 严格校验版本(不匹配抛异常),结构变更走 bump 版本。

## 4. FrameTime 用法

- `IFrameTime.Frame / DeltaTime / Time` 公开语义不变;内部时间为 Q32.32 累计
  (N 步后 `TimeRaw == N × 单步 raw`,整数加法无漂移)。
- **秒→帧换算请走 `TimeToFrame(seconds)` 或直接用帧数配置**,不要自己
  `Time + seconds` 再换算(那是 float 加法,精度语义弱于定点路径)。
- 冷却/计时推荐直接用毫秒整数(`CooldownEndTimeMs` 模式)或帧数。

## 5. 新增数值字段 checklist

- [ ] 模拟态字段类型用 `Fixed64`(向量用 `FixedVec3`)
- [ ] 需要开方/归一化/三角 → 走 `DeterministicMath` / `DeterministicMathBridge`,禁止 `MathF.` / `Mathf.`
- [ ] 配置/表现边界单次换算(入 `ToFixed`,出 `ToSingle`),集中在一个 convert 类里
- [ ] 进回滚快照 → raw long + payload 版本 bump
- [ ] 进状态哈希 → `MobaStateHashBuilder.AddLong(RawValue)`(不要 `AddFloat` 包定点值)
- [ ] 验收:golden raw 断言(锁位)+ 回放哈希对账,不是"数值看起来差不多"

## 6. 已知边界与后续项

- 属性系统(`AttributeGroup`)仍为 float 存储:基本运算位一致,读取处单次换算;整块迁定点未排期。
- ~~EffectContainer / BehaviorRuntime / buff-Continuous 计时链~~ 已定点化(2026-08-15/16):
  `EffectInstance` 与 `BehaviorRuntime` 计时 raw long 累加;`MobaContinuousRuntimeBase`
  承载 `ElapsedRaw`/`IntervalRemainingRaw`,`MobaContinuousTickProcessor` 全整数推进
  (含整数版余数归一),`BuffContinuousRuntime` 时长 raw + `RefreshRaw`,
  Buff 回滚 payload **v3**(raw long,无限期=long.MinValue 哨兵)。
- **模拟域 float 秒累计已全部清零(2026-08-16 收尾批)**:motion 三处源级计时
  (`FixedStepRunner`/`FixedDeltaMotionSource`/`TrajectoryMotionSource`,附 6 个契约测试)、
  HFSM `DelayBehaviour`/`TimeoutBehaviour`(hfsm 包已接 Deterministic;快照 FloatValue 为边界视图)、
  ability 旧引擎 `Interval/Delay/AttributeEffectDuration RunningAction`、`SkillPipelineContext.ElapsedTime`、
  `SkillTimelinePhase`(整数 ms 换算)、`MobaTimelinePlayer`、`MobaGameplayService`、`MobaTimeLimitRule` 全部 raw 化。
  **保留 float/double(裁定)**:`MobaBattleDriverHost.LogicTimeSeconds`(会话/表现域,跨包接口 double 消费者众多)、
  `MobaBuffStateRecoveryProvider`(重连重建,两端一致的 float 视图边界)、`MotionState.Time`(公共状态字段)。
- 跨运行时 JSON float 解析(.NET 服务端 vs Mono/IL2CPP 客户端)存在理论末位差;
  当前服务端权威+同构客户端模型不触发,纯跨运行时 P2P 锁步前需评估 decimal-string 配置通道。
- Luban 表字段全 int,无数值漂移;Configs/moba float 参数在 PlanAction 边界单次换算。

## 7. 路线图快照

P0 包闭环 → P1 弹丸运动学 → P2 碰撞/运动/散点+Core 根治(MathUtil.Sqrt 定点)
→ P3 伤害/资源/护盾管线 + FrameTime 定点 + HP 双存储统一 → P4 bridge 收敛(Core 唯一实现)、
发布衔接(本文档) → 审计修复(三角/遍历序/整数对齐)+ buff/motion/HFSM/管线计时收尾(本节 §6)。
