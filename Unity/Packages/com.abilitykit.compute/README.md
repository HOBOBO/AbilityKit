# AbilityKit 计算

`AbilityKit.Compute` 定义可移植的批量计算内核、后端链、验证、回退和观测契约。
它不安装全局后端，也不替代业务包的托管实现语义。

平台加速由应用装配入口显式选择，并按配置顺序尝试。不可用或拒绝的后端不会阻止尝试下一项；可用性探测或执行抛出异常时，后端链记录 `Faulted`，也继续回退。没有配置后备项时，不会隐式添加托管后端。

业务方应为加速结果提供验证器；`Execute` 未收到验证器时不会自动检查业务值。失败和拒绝不回滚输出缓冲区，只有返回成功时才能消费本次请求的有效输出。

可选的 Unity Jobs 实现位于 `com.abilitykit.compute.unityjobs`。
