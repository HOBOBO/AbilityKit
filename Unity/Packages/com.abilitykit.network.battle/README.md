# Network Battle

`com.abilitykit.network.battle` 提供以 opcode 和 codec 回调装配的战斗输入与推送数据面。

## 安装与首次使用

从项目配置的包来源安装；版本、Unity 最低版本和直接依赖以 [package.json](package.json) 为准，同时满足传递依赖与所需第三方程序集的条件。本轮核校基于仓库源码与 .NET 镜像，不等于隔离安装或 Unity 发布验收。

先运行使用指南的借用 SDK 构造示例，再接入项目协议。调用方式不决定帧同步或状态同步模式；连接建立不等于鉴权和恢复完成。
