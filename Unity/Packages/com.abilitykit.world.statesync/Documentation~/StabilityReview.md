# 稳定性评审

## 可以复用的边界

| 组件 | 结论 | 接入条件 |
| --- | --- | --- |
| `SnapshotBuffer` | 推荐作本地帧历史。读写复制、有界保留、按帧号查询，计数和容量与其他操作共用同一把锁。 | 底层缓冲交由包装器独占访问；单次操作可并发，不保证多次读取为原子视图。 |
| `StateManager` | 推荐作单一模拟执行线上的已注册实体检查点。捕获先完成实体回调，再在锁内更新缓冲与历史。 | 同一历史窗口不复用实体 ID；回调异常向外传播，恢复不是事务，也不重建对象。 |
| `PredictionCoordinator` | 可作为局部预测试点：独立的有界输入与快照历史、同帧输入顺序、权威覆盖与后续帧重演。 | 宿主保证权威观测粒度、输入终结来源、历史窗口与槽位复制；不能直接把快照 ID 或帧同步确认当作输入终结。 |
| `ClientPredictionModule` | 保留实体级兼容入口；不会重演待确认输入。 | 当前 `Tick` 的确认帧是本地推进值，不是服务器确认；不要选它实现完整预测对账。 |
| `StateDiffProvider` / `DeltaCompressor` | 独立兼容工具，不是固定基线协议。 | `StateDiffProvider` 产出的 `FromFrame`/`ToFrame` 目前是零；调用方自行保证基线身份。`DeltaCompressor` 未发现正式消费者，保留公开面，不作为推荐入口。 |
| `AoiInterestSet` | 可复用的观察者可见性评估，不负责恢复范围和生命周期。 | 每个观察者独立、串行评估；预算和优先级由宿主另行处理，临时结果仅当轮使用。 |
| `StateHashValidator` / `KeyFrameStrategy` | 分别用作诊断比较和本地计划，不参与权威状态准入。 | 缺样本不是一致性证明，计划帧也不证明存在可恢复的状态。 |
| `Events` | 供本地观察、诊断和表现接入，不是权威提交事件流。 | 校正和推进分别发布通知；使用方避免重入，不修改槽位值引用，不依赖订阅方异常触发回退。 |

## 仍需验证的风险

- **实体身份**：恢复用 ID 查当前注册实体，不验证代际；注销后复用 ID 可能把旧状态交给新实例。先由宿主禁止复用或清空历史；不要在包结构整理中擅自改恢复资格。
- **历史所有权与异常**：本地实体快照适配器必须返回可独立保留的数据。`RollbackState` 直接保留调用方交付的数组，不做防御性复制；交付后不得写入，恢复也不得改写历史。`InputBuffer` 按引用存命令，命令在历史有效期内必须不可变；其 `PeekLocalInput` 在锁内执行调用方谓词，禁止阻塞或修改缓冲。两类历史都不提供跨调用事务。
- **历史覆盖**：`PredictionCoordinator.RollbackReplayEnabled` 只表明配置允许重演。找不到对比帧的快照时使用当前槽位；输入历史被淘汰时，缺失帧和未输入帧均以空批次返回。目前不能用“重演成功返回”证明历史完整。
- **在线状态流**：权威快照的准入、固定基线重建、导入成功后提交、重连与表现退出属于消费层。帧同步按命令和自己的检查点推进，两者可以共用业务世界或值状态，不共用游标与恢复资格。
- **发布准备**：本批只验证工作区源码。剩余 Runtime 的全量中文 XML 注释、公开 API 基线、隔离包安装与 Unity Player 尚未作为发布门禁验收。不得据此宣称整个包已达 Core 的发布标准。

排查和验收限定仓库源码、进程内类型化对象与自有测试；不抓包、不排查外部网络字节、不解析网络载荷。线上联调另行安排。
