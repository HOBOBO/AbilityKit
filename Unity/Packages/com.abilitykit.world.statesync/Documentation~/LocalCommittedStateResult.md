# 离线权威提交结果契约

状态：**双提交边界已补本地联动测试**。适用于单一执行线上的进程内类型化状态；不新增 Runtime API、回调、协议字段或生产接线。现有[本地状态提交示例](../Samples~/LocalStateCommit/README.md)验证隔离导入与游标更新；联动夹具另外验证准入游标和固定基线缓存分别提交时的交付边界。

## 何时可交付

固定基线的顺序是：**校验并重建候选 → 成功导入或应用 → 提交准入游标 → 提交基线缓存及物化状态 → 返回已提交结果**。夹具同步返回可选结果，不在两处提交之间调用消费者。只有两处提交都成功、会话代际与状态流仍是当前作用域，才交付一次结果。重复或迟到候选不再次交付；准入检查不能提前推进游标。

| 阶段 | 责任与边界 |
| --- | --- |
| 接纳候选 | 校验作用域、基线与候选顺序。旧作用域、重复、迟到候选只忽略；当前基线确实失配则由宿主报告失效。 |
| 导入与两处提交 | 导入成功才提交准入游标、基线缓存及物化状态。在任一提交失败或中止时，都不交付结果。若导入或部分提交后无法确认状态仍可信，宿主报告基线失效，隐藏原预测并等待新全量；不假设两处写入有事务，也不承诺失败修订总能原样重试。 |
| 对账与表现 | 对账仅读取已提交的值和可选的独立终结证明，不反向修改复制提交或全量请求；不把现有远端表现通知当成提交凭证，也不新增通知。 |

会话切换期间旧候选完成，不得交付给新作用域，也不得把旧作用域的失败报告到新作用域。全量请求受理、收到全量或仅导入成功都不解除恢复等待；只有当前作用域的新全量完成两处提交才解除等待。结果中的全量标志取自原候选的类别，物化后的增量即使包含完整实体视图也不能充当恢复全量。

## 最小结果与证明

下列字段是夹具契约，不是新增的公开类型或序列化格式：

| 项 | 来源与校验 |
| --- | --- |
| 复制作用域 | 宿主提供的会话代际、世界和状态流；修订只在该作用域内比较。 |
| 提交修订、权威 Tick、全量标志 | 修订为正且严格递增，Tick 非负且不倒退，同 Tick 可接受更新修订。全量标志来自提交前已校验的原候选。 |
| 已提交状态投影 | 从导入并提交的结果提取自包含值，不能用导入前的原候选替代，也不能持有可写的世界引用。只有取得受控实体的移动投影和实体生命周期、控制者、输入代际，才组装 P0 的 `CommittedMovement`。投影或身份依赖缺失时保持权威显示，不阻塞复制提交。 |
| 独立终结证明 | 可选，缺省为无证明；由夹具中的独立权威输入账本给出，与完整对账作用域、修订、Tick 精确匹配。不得从快照 ID、事件水位、帧同步确认、已提交游标或最大收件序号推导。只接受满足[连续前缀契约](LocalReconciliationProposal.md#输入终结与重演)的证明。 |

新全量提交但无匹配证明时，权威状态仍恢复可用；预测保持关闭，同一输入代际下的待终结输入全部保留。有有效证明只裁剪已终结前缀；能否重演还要独立验证 Tick 覆盖与步进条件。重演失败不撤销权威提交，也不将已终结输入重新加入队列。

## 验收用例

| 场景 | 应验证的结果 |
| --- | --- |
| 导入失败或准入游标提交失败 | 不交付、不调用对账；后续提交步骤不执行。 |
| 准入已提交，基线缓存提交失败 | 不交付结果、也不发布候选；保留待终结输入并进入全量门禁，不假设已写游标能回退。 |
| 两处提交成功 | 恰好交付一次，使用实际导入结果；同 Tick 的新修订可交付，重复候选和尚未提交完的候选不可交付。 |
| 旧会话代际的候选迟到或完成 | 切换后才到达则不导入；切换前已进入提交的候选，无论基线步骤成功或失败，都不交付、不改新作用域的游标或缓存，也不使其基线失效。 |
| 基线失效后收到物化增量，或全量仅完成部分步骤 | 保持等待，不消费任何随附证明。 |
| 新全量提交，无证明或证明不匹配 | 解除全量等待，只更新权威锚点，不裁剪与不重演。 |
| 同截面证明有效、覆盖完整 | 仅裁剪有证据的前缀，按 Tick 重演剩余输入并推进明确无输入的 Tick；若步进失败，仅丢弃预测候选。 |

`LocalCommittedStateResultTests` 复用提交示例与 P0 对账器，让两个提交步骤分别返回失败，验证部分提交、成功交付、重复候选以及全量恢复。会话切换用同步夹具在旧基线步骤完成前建立新会话，分别检查旧步骤成功和失败后的隔离；不依赖真实并发或计时。仅使用本仓库源码与测试进程内的类型化对象；不抓包、不查询线上水位、不读写或解析网络载荷、不启动网络服务、不检查项目外进程或对象。通过夹具不等于证明生产具备事务、独立终结来源或可接入 MOBA；生产方案须另行确认。
