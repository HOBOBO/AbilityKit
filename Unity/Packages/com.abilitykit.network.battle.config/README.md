# Network Battle Config

`com.abilitykit.network.battle.config` 提供面向 Room Gateway 协议的战斗配置构建器。

## 安装与首次使用

从项目配置的包来源安装；版本、Unity 最低版本和直接依赖以 [package.json](package.json) 为准，同时满足传递依赖与所需第三方程序集的条件。本轮核校基于仓库源码与 .NET 镜像，不等于隔离安装或 Unity 发布验收。

先运行使用指南的本地配置示例，再提供真实输入 codec 和会话身份。Build 只检查部分必填项，返回同一份可变 Options。
