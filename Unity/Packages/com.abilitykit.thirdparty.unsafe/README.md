# System.Runtime.CompilerServices.Unsafe for Unity

This package contains `lib/netstandard2.0/System.Runtime.CompilerServices.Unsafe.dll`
from the Microsoft NuGet package `System.Runtime.CompilerServices.Unsafe` 5.0.0.
It supplies the precompiled reference required by MemoryPack 1.10.0 in Unity.

Source: https://www.nuget.org/packages/System.Runtime.CompilerServices.Unsafe/5.0.0
License: MIT (see `LICENSE.txt`).

The managed assembly is distributed as part of this package. Consumer projects
must include this package through their package dependency closure; no copy from
the source project's `Assets/Plugins` directory is required.
