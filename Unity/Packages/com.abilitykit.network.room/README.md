# Network Room

`com.abilitykit.network.room` 提供Room Gateway 线协议客户端、连接会话和分阶段房间流程。

## 安装与首次使用

从项目配置的包来源安装；版本、Unity 最低版本和直接依赖以 [package.json](package.json) 为准，同时满足传递依赖与所需第三方程序集的条件。本轮核校基于仓库源码与 .NET 镜像，不等于隔离安装或 Unity 发布验收。

先按使用指南选择已有 SDK 上的房间能力、仅连接会话或自动房间流程。建连、认证、入房、开战和订阅分别检查。
