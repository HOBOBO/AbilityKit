# Network SDK

`com.abilitykit.network.sdk` 提供通用客户端连接、单一请求链、协议 Agent 与共享客户端 Hub。

## 安装与首次使用

从项目配置的包来源安装；版本、Unity 最低版本和直接依赖以 [package.json](package.json) 为准，同时满足传递依赖与所需第三方程序集的条件。本轮核校基于仓库源码与 .NET 镜像，不等于隔离安装或 Unity 发布验收。

先运行使用指南中的延迟工厂完整示例，再按服务端协议配置响应包络和 dispatcher。Build 成功不表示已建连或完成业务鉴权。
