本文保留旧文件入口，说明影响包消费者的限制。API 的支持等级以[首发支持清单](FirstReleaseSupport.md)为准；包版本以 [package.json](../package.json) 为准。

## 依赖与消费条件

Core 直接依赖 Deterministic。独立安装时必须能解析这一依赖，不能把本仓库的本地嵌入包解析当作外部安装已经验收。纯运行时程序集不引用 Unity 引擎，编辑器适配独立交付；使用方仍需验证自己的环境和安装来源。

## 当前发布缺口

| 项目 | 消费者需要知道的边界 |
| --- | --- |
| API 与职责 | Observability 等待准入项不因公开签名或测试存在而自动提升为正式推荐面；见[观测契约](Observability.md) |
| 数学结果 | Fixed64 存在 Int128 与 decimal 路径差异，见[定点桥接](DeterministicMathBridge.md)；不能承诺完整跨目标位一致 |
| 独立消费 | 既有本地 .NET 与 Unity Editor 制品验证不等于计划注册表的传递安装、正式旧版升级或所有 Player 平台支持；见[独立消费范围](IndependentConsumption.md) |
| 候选状态 | 构建、注释、API 基线或局部测试通过，均不能替代正式发布签核 |
