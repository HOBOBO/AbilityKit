# Core 与 Deterministic 独立消费范围

> 文档类型：消费指南与历史验收范围说明
> 核校状态：2026-11-24 核对依赖声明与使用限制；本轮没有重跑隔离 Unity 安装或制品替换。原验证器操作与历史原文保存在仓库 Core 稳定化记录。

Core 的纯运行时依赖 Deterministic。首次调用见[使用指南](Usage.md)，支持分级见[首发支持清单](FirstReleaseSupport.md)，候选限制见[发布缺口](ValidationAndReleaseReadiness.md)。

## 安装前核对

1. 通过项目约定来源安装 Core，确保同一项目可解析 `package.json` 声明的 Deterministic 版本；不要只复制 Core 的源码或 DLL。
2. 自定义 asmdef 引用实际使用类型所属程序集；同时使用定点公开类型时需要显式引用 `AbilityKit.Deterministic`。
3. 在自己的宿主编译并执行最短示例，再验证实际使用的 API、生命周期和失败路径。包可安装与业务可运行分别验收。
