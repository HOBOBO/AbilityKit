# 旧 Unity 设置引导兼容契约

2026-11-21：经维护者确认，从 Core 候选中退役 `AbilityKit.Core.Configuration.UnityJsonSettingsBootstrap` 及 `AbilityKit.Core.Unity` 程序集。原类型、程序集引用均不再可用；应用应在自己的宿主中承担设置引导，仍可复用 Core 的 `LayeredJsonSettingsStore`。MOBA 已有独立实现，本次不改动。

下文记录旧版本行为，用于迁移已有源码引用，不是当前包支持契约。

本页记录旧实现的真实行为。底层文件工具见 [配置文件、缓存与模块描述兼容契约](./ConfigurationFileCompatibility.md)，持久层替换见 [LayeredJsonSettingsStore](../Runtime/Config/LayeredJsonSettingsStore.cs)。MOBA 的同名类型位于独立应用命名空间，短类型名相同不能证明使用了旧 Core API，也不能证明迁移行为等价。

## 路径与首次复制

全部入口仅在文件名为空引用时采用 `abilitykit.settings.json`；空字符串和空白不会转换为默认值。文件名直接交给 `Path.Combine`，不验证相对路径、扩展名、JSON 格式或目标是否位于持久目录内。绝对路径和 `..` 的结果遵循平台路径规则，不能把根路径拼接当作目录沙箱。

`EnsurePersistentCopy` 是延迟执行的迭代器，调用方法本身不会访问路径或发送请求。枚举推进时，持久根路径为空则结束；目标文件已存在也直接结束，不读取、校验或更新已有内容。它不比较 StreamingAssets 的版本。

源路径由 StreamingAssets 根路径与文件名拼接。字符串不含 `://` 时只添加字面的 `file://` 前缀，没有 URI 转义或标准化；这不保证任意平台路径都能被请求正确解释。请求由 `UnityWebRequest.Get` 创建，等待 `SendWebRequest` 后检查结果。非 Success 或下载文本为空引用/空字符串时静默结束；非空白文本与纯空白文本均不作 JSON 校验。

请求使用跨等待点的 using，在正常退出或枚举器被 Dispose 的路径上释放。停止协程、宿主销毁、域重载等场景中是否及何时释放，仍需按真实 Unity 行为验收。

| 阶段 | 失败边界 |
|---|---|
| 获取平台路径、路径拼接、请求创建和发送、结果/文本访问与请求释放 | 不在落盘 catch 内，异常可能传播。 |
| 请求返回失败结果或空文本 | 静默结束，不返回成功标志或诊断。 |
| 最后取得父目录、创建目录和直接写入 | 捕获异常并结束，已发生的目录或文件副作用不回滚。 |

下载后不再次检查文件存在。其他调用在下载期间创建目标时，本次写入仍可能覆盖它。写入没有临时文件、原子替换、备份或跨调用同步；这些是保留的兼容限制。

## 协程与同步加载

| 条件 | `LoadPersistentInto` | `LoadPersistentIntoSync` |
|---|---|---|
| 空目标存储 | 枚举推进时结束。 | 直接返回。 |
| 空反序列化回调 | 仍先尝试复制，随后文件工具返回空设置并替换持久层。 | 直接返回，保留原持久层。 |
| StreamingAssets 复制 | 先 yield 嵌套复制枚举器；复制静默失败后仍尝试读取目标。 | 不复制，不发送请求。 |
| 持久根路径为空 | 加载阶段结束，保留旧层。 | 返回，保留旧层。 |
| 文件缺失、读取或解释失败 | 文件工具返回空设置，清空原持久层并通知。 | 同样清空并通知。 |

协程需要 Unity 宿主推进等待项。仅手动调用外层枚举器的 MoveNext 不会自动遍历其 Current 中的复制枚举器，不能据此验证首次复制。复制与随后的加载分别读取 `Application.persistentDataPath`，没有跨等待点的根路径快照。

成功取得设置对象后，`ReplacePersistent` 先清空并重建持久层，再同步发送键为 null 的变更通知，即使新层为空也通知。基础层与覆盖层保持原状，覆盖层仍优先。通知异常会传播，已提交的持久层不回滚；不能把读失败、空设置或通知失败理解为保留旧配置。外层的路径拼接也不受文件工具内部 catch 保护。调用与存储访问需要由同一所有者协调，本工具不提供线程同步。

## 保存与迁移

`TrySaveOverridesToPersistent` 在序列化回调为空或持久根路径为空时返回 false；随后在文件工具 catch 之外拼接路径，再调用 `JsonSettingsFiles.TrySaveOverrides`。因此 Try 前缀不表示所有异常都转换为 false。

非空字典原样交给回调，不生成快照；空字典引用由文件工具替换成新空字典。回调返回空引用会写入空文本。工具先创建父目录再调用回调并直接覆盖写入，捕获失败不回滚已发生的副作用。此入口只写文件，不替换任何设置层、不清对象缓存，也不发送通知。

迁移应由应用明确文件来源、允许路径、失败诊断、空回调语义、覆盖写入、协程所有权与通知责任，针对已有配置执行升级与回退验证。需要原子保存、重试、内容版本或并发屏障时，应在所属包另行设计，不扩大 Core 配置职责。

## 验证范围

本类型从未进入 Core 的 .NET 镜像；.NET 测试不证明旧请求和协程行为。应用层迁移后的请求、中止、资源释放及平台权限由实际使用方验证。
