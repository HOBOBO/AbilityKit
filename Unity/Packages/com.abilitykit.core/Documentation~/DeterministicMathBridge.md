# 定点数学桥接契约

DeterministicMathBridge 位于 Runtime/Mathematics，公开命名空间为 AbilityKit.Core.Mathematics。它复用 com.abilitykit.deterministic 的 Q32.32 类型与数学内核，提供 float、Vec3 和 Quat 的边界入口。源码不依赖 Unity 引擎；碰撞与运动框架包使用其中的转换、长度、归一化和角度函数。

浮点数学原语自身的契约见 [数学原语契约](./Mathematics.md)。本桥接既不改变调用方已有的浮点表达式，也不接管坐标单位、领域范围校验或完整模拟数值链。

## 转换、表示范围与精度

Fixed64 使用有符号 64 位原始计数表达 Q32.32，分辨率为 2^-32，表示范围为 [-2147483648, 2147483648 - 2^-32]。float 输入通过 double 中间值乘以 2^32，再以 checked 转为 long，向零截断。

有限 float 并不都能转换。正侧 float 值 2147483648 会溢出，其前一个可表示值 2147483520 可转换；负侧 -2147483648 可以转换。小于一个定点计数的正负输入均可能量化为零，有符号零不会保留。

| 入口 | 非有限输入 | 有限输入超出转换范围 |
|---|---|---|
| ToFixed(float) | NaN 与正负无穷归零 | 抛 OverflowException |
| ToFixed(in Vec3) | 任一分量非有限时抛 ArgumentOutOfRangeException | 抛 OverflowException |
| Normalize(in Vec3)、Magnitude(in Vec3) | 先严格转换分量，拒绝非有限值 | 转换或中间运算可抛 OverflowException |
| Normalize(in Quat) | 四个分量分别严格转换，拒绝非有限值 | 转换或中间运算可抛 OverflowException |
| Sqrt(float) | 严格转换，拒绝非有限值 | 抛 OverflowException |
| Sin、Cos、Tan、Atan2、Exp、Ln、Pow | 每个参数先经标量守卫归零，再进入内核 | 仍可因转换或运算溢出而失败 |

非有限值归零是现有标量兼容契约，不能推断为全类统一的容错策略。改成统一抛出或统一归零都会改变使用方行为，需要单独评审。

ToSingle 与 ToVec3 返回浮点近似视图。定点原始计数为 2^32 + 1 时，转换为 float 得到 1，再转回会丢失最低计数。Fixed64.MaxValue 转成 float 会舍入为 2147483648，再转回会溢出。因此不能把浮点视图当成无损存储格式。

Epsilon 的原始计数为 4294，是 MathUtil.Epsilon 向零量化后的结果；桥接的归一化并不使用它作为近零阈值。

## 长度与归一化

向量先严格转换各分量，按既有分量乘法与求和顺序计算定点平方和，再交给定点开方。向量的定点长度为零时返回零向量；四元数的定点长度为零时返回 Quat.Identity。

两个回退都可能作用于非零输入。例如仅 X 分量为 2^-32 时，分量本身可以转换，但其平方量化为零，向量长度与归一化结果均为零，四元数归一化则返回恒等值。仅 X 分量为 2^-15 时，定点平方仍非零，可以得到单位 X 方向；不能套用其他归一化入口的 Epsilon 策略。

分量可表示不代表几何计算可表示：

| 输入示例 | 失败位置 |
|---|---|
| (50000, 0, 0) | 单个分量的定点平方超出范围 |
| (40000, 40000, 0) | 每项平方可表示，但求和超出范围 |
| 对应分量构成的四元数 | 同样受平方与求和范围限制 |

上述失败传播 OverflowException，不自动缩放、不回退为浮点长度，也不返回饱和值。返回 float 后还会发生舍入，不承诺单位长度在所有输入下都精确等于一。

## 严格开方

Sqrt 先使用 Fixed64.FromSingle，随后由定点内核检查量化后的值。非有限输入失败；量化后为负的输入抛 ArgumentOutOfRangeException；转换超范围抛 OverflowException。

因此 -2^-33 先量化为零，可以返回零，而 -2^-32 仍为负值并失败。正的 2^-33 同样返回零，正的 2^-32 返回 2^-16。本入口不同于 MathUtil.Sqrt 的混合定点与系统开方回退，不会为超范围值自动采用 System.Math.Sqrt。

## 三角函数与方向角

Sin、Cos、Tan 使用弧度，标量非有限输入按零角处理。内核使用量化后的角度做归约和 CORDIC 计算；结果是定点近似再转回 float，不能假定所有特殊角度都具有精确数学值。

Tan 实际执行定点正弦除以余弦。余弦为零时可抛 DivideByZeroException，除法范围溢出时可抛 OverflowException。底层旧注释中的“极点附近饱和”不能作为本入口的保证；本批保留实际除法行为。

Atan2 的参数顺序是 y、x，分别执行标量守卫。零向量得到零；零 y 和负 x 得到正 π；x 为零时，正负 y 分别得到正负 π/2。定点转换不保留负零，例如 Atan2(-0, -1) 返回正 π，不沿用浮点负零分支。通用输入继续受定点内核的表示及中间运算边界限制。

## 自然指数、对数与幂

Exp 对非有限输入先归零，因此返回一。精度下溢可以得到零，例如 Exp(-24)；结果或中间运算超范围则抛 OverflowException，例如 Exp(22)。不能套用 float 自然指数的可表示范围。

Ln 要求守卫和量化后的值严格为正。非有限值、零、负值以及不足一个定点计数的微小正值都会失败。Ln(1) 返回零，Ln(2^-32) 有效；有限输入超转换范围则先抛 OverflowException。

Pow 先分别转换底数与指数，按量化后的指数判断是否为整数：

| 量化后的输入 | 既有行为 |
|---|---|
| 零底数、正指数 | 返回零 |
| 零底数、零指数 | 返回一 |
| 零底数、负指数 | 抛 DivideByZeroException |
| 负底数、非整数指数 | 抛 ArgumentOutOfRangeException |
| 整数指数 | 使用内核整数幂路径，保留奇偶符号 |
| 正底数、非整数指数 | 经内核对数与指数路径计算 |

定义域成立也不保证成功：负整数指数仍可能因先计算正幂的中间结果溢出而失败，Pow(2, -63) 就属于这一情况。最小负定点底数 -2147483648 的整数幂在取绝对值时溢出，即使指数为零也如此。不能把“任何底数的零次幂都返回一”写成无条件 API 承诺。

非有限指数归零，例如 Pow(2, NaN) 返回一；非有限底数归零，例如 Pow(NaN, 2) 返回零。这些结果来自守卫与内核的组合，不等于标准浮点幂函数的非有限值规则。

## 确定性边界与待评审依赖

本桥接为给定输入提供明确的转换和定点调用路径，不能单独证明完整碰撞、运动或战斗调用链跨平台位一致。调用前的浮点平方和、坐标变换、输入舍入以及调用后的浮点运算仍需要各自证据。

本批只读核对还发现底层 Fixed64 存在需要独立评审的编译目标差异：NET7_0_OR_GREATER 下的乘法使用 Int128 乘积右移，其他目标使用 decimal 除以 2^32 再转 long。对于精确负小数乘积，两条路径的截断方向不同；例如原始计数 -1 与 1 相乘，右移路径得到 -1，decimal 转换路径得到零。decimal 中间乘积还有自身的范围限制。

这属于定点依赖包的兼容与跨目标算术问题，本批没有更改内核、选择舍入策略或新增平台保证。修复前应明确统一语义、已有持久化和黄金向量影响及目标平台验证方案，再实施对应变更。Unity、Mono 和 IL2CPP 的实际结果仍需在各目标验证。
