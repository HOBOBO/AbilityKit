# AbilityKit MOBA View Runtime

`com.abilitykit.demo.moba.view.runtime` 是 MOBA 示例的客户端流程、会话与 Unity 表现运行时。它负责把运行时数据接到表现，不替代权威战斗模拟。

从项目配置的包来源安装本包，Unity 版本和依赖以 [`package.json`](package.json) 为准。接入已有 MOBA 示例时，从[客户端流程规格](Runtime/Game/App/Flow/MobaFlowSpec.md)和[使用与源码导航](Documentation~/Usage.md)确认装配与表现绑定，不用手工注册旧版 transport 或调试 Feature 代替正式装配。

- [早期专题索引](Document/README.md)：保留历史入口；跨包设计从仓库的 `Docs/design/00-index.md` 查阅。

## 本地英雄技能训练

在 Unity Editor 或 Development Build 的本地示例战斗中，打开左侧「英雄技能训练」面板：

- **技能与资源**：无冷却和无限法力默认关闭，仅对开启时的主控英雄生效。无冷却跳过常规主动技能（含大招）自身的冷却，不改变施法校验、前后摇、共享／全局冷却、充能和普攻间隔。关闭后后续施放正常计时。无限法力只免除法力支付，不补血或改动其他资源；「补满技能资源」与「重置技能冷却」各自独立。选技能槽可按等级表调整该槽的 Rank，不改变英雄等级、已有的冷却或已经开始的施法。
- **目标与场景**：输入相对主控位置的世界 X/Z 偏移，放置一个不会主动行动、但能正常承受战斗效果的敌方固定靶。「清除固定靶」不会移除原有敌方英雄。
- **观测**：显示主控英雄的最近一次命中、累计伤害、命中次数和最近施法失败原因。测连招前点「清零伤害统计」；输入目标 Actor ID 只统计该目标，留空统计全部目标。打开范围显示后，绿圈为普攻，蓝圈为指定技能槽的施法范围；留空时距离测量选最近敌方单位。切换主控或更换英雄会清空读数。

这些选项属于本地训练会话，不写入英雄配置、联机协议或回放数据。
