# Tiny Logic

This package contains only the deterministic Tiny battle rules. It has no Unity engine or AbilityKit package dependencies. Start with `TinyBattle`, `TinyInput`, and `TinyBattleStateCodec`; networking and presentation live in `com.abilitykit.demo.tiny`.

Import the `01 Logic` sample to run a battle, restore a checkpoint, and compare 40 frame hashes. In the source repository, run `dotnet run --project src/AbilityKit.Demo.Tiny.Logic.Sample` for the same code without Unity.
