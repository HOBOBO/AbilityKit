# 01 规则与确定性

**目标：** 用同一组输入在 Unity 和 .NET 得到相同状态与哈希。本章只涉及战斗规则，不引入连接、Room 或 Unity 表现。

## 章节契约

- 前置：阅读 [00 从这里开始](00-从这里开始.md)；仅安装 `com.abilitykit.demo.tiny.logic`。
- 项目实现：`TinyInput`、`TinyBattle`、`TinyBattleState`、`TinyBattleStateCodec`，明确输入合法性、稳定遍历顺序、快照完整性与哈希字段。
- 框架关系：本章先证明规则本身确定；回滚基础设施从 04 开始引入。规则不得引用 `UnityEngine`、网络 SDK 或表现对象。
- 教学代码：只展示创建两名玩家、提交输入、推进 Tick、捕获状态与计算哈希的最小调用；不复制一份简化规则。

## 验收与边界

导入 Logic 包的 `01 Logic` 样例后运行 `TinyLogicExample.Run()`；它返回最终状态哈希，状态分叉则抛出异常。仓库内可直接运行：

```powershell
dotnet run --project src/AbilityKit.Demo.Tiny.Logic.Sample
./tools/create-tiny-logic-validation-project.ps1
```

样例先捕获并编码快照，再恢复到新战斗实例；后续 40 帧逐帧比较哈希。正式源码位于 `Unity/Packages/com.abilitykit.demo.tiny.logic/Runtime/Logic`，由 `src/AbilityKit.Demo.Tiny.Core` 共编译。独立 Unity 工程 EditMode 测试在完整门禁中运行。

不在本章加入随机数、浮点物理、Unity 对象引用或网络时钟；这些会模糊确定性边界。
