# 网络 I/O 计数器及恢复游标

## I/O 计数器

`ConnectionManager.GetDiagnosticsSnapshot()` 公开当前运行时会话的累计字节数及已成帧数据包数：

- 接收字节统计传输交给帧解码器的载荷字节；发送字节统计交给传输的已编码帧，不包含 TCP、WebSocket、UDP 和 KCP 等传输包头或分帧开销。
- 仅在完整 AbilityKit 帧解码或发送后递增包数。一个帧分散到多次接收回调时，每次回调累计字节，解码完成后计一个包。
- 计数器用于监控及排障，不是确认、持久化序列号或重连游标。新运行时会话使用新的计数器集合。

## 恢复状态

重连协议必须使用能表示服务端已提交内容及客户端已应用内容的应用状态。既有同步功能提供合适基础，包括快照序列号、权威帧号及可靠事件接收或确认游标。应用应发送符合自身恢复模型的游标，由服务端结合当前会话代际或恢复令牌验证。

不得用传输计数器推断服务端接受了哪些玩法操作。TCP、WebSocket、KCP 的投递及重连行为不同，应用也可能通过另一种传输重连。因此恢复契约属于协议消息，并保持传输无关。
