# MOBA 八英雄技能机制对齐审计

> 基线：仓库当前生产配置、Trigger Authoring source 与 8 个英雄的无头验收。用于记录机制覆盖和下一批实现顺序；上线平衡数值仍需按当前正式服版本核准。

## 审计口径

只把运行时状态、位置、命中、伤害、控制、冷却和目标选择的验收视为机制证据。存在 Trigger、特效或 trace 节点本身不代表机制正确。官方技能存在版本调整时，以目标发布版本为准，本文不固定伤害数值与冷却数值。

## 被动机制核对基线

以下表格记录当前目标版本的触发语义。它区分“何时进入被动”和“被动产生什么结果”，避免把一个英雄的命中计数规则套到另一个英雄；数值仍以生产配置和目标版本为准。

| 英雄 | 被动入口 | 当前行为 | 核对/验收状态 |
|---|---|---|---|
| 廉颇 | `skill.cast.complete`、`damage.apply.after` | 释放技能获得霸体/战意状态；造成和承受有效伤害分别积累怒气；脱战后将怒气转为恢复 | 已有怒气、上限、脱战恢复和非本英雄隔离验收；待补技能释放中断边界 |
| 小乔 | `skill.cast.complete` | 释放任意主动技能后获得短时移速 Buff，重复释放刷新持续时间，不叠加移速 | 已有释放后速度、到期和重复刷新验收；这是当前目标版本的明确契约 |
| 赵云 | `damage.apply.before` | 按自身缺失生命比例降低最终受到的伤害，并在低生命区间封顶 | 已有满血、半血和极低血量的比例验收；待补属性变化和死亡边界 |
| 墨子 | `skill.cast.complete`、`damage.apply.after` | 技能释放刷新护盾；普通攻击有效命中计数，第四次触发强化近战、击退并刷新护盾 | 已有护盾和第四次命中验收；“未命中是否计数”仍需目标版本确认，不能直接套用鲁班出手计数 |
| 妲己 | `damage.apply.after` | 技能伤害命中叠加目标印记，最多三层；后续技能按层数提高伤害 | 已有三层上限和最终伤害验收；待补多目标转移及目标死亡后的层数清理 |
| 嬴政 | `damage.apply.after` | 普通攻击命中计数，达到阈值触发强化普攻伤害 | 已有第五次强化伤害验收；未命中计数语义待目标版本确认 |
| 孙尚香 | `damage.apply.after` | 普通攻击命中后分别缩短三个主动技能冷却，已就绪技能保持就绪 | 已有三槽缩短、短冷却钳制和就绪技能验收；数值按目标版本核准 |
| 鲁班七号 | `skill.cast.start` | 仅普通攻击出手增加计数；第五次触发扫射替换攻击，扫射本身不再计入下一轮 | 已有未命中计数、扫射排除和第二轮阈值验收 |

其中小乔的“释放技能即加速”和鲁班的“普通攻击出手即计数”是不同事件语义，不能通过统一的 `damage.apply.after` 监听替代。后续补齐其他英雄时，先为每个入口补空放、未命中、命中和替换技能边界，再调整正式服版本数值。

## 下一批实施顺序

### 鲁班七号本轮基线更新

- 一技能已按官方技能语义改为 2 秒移速削弱，手雷爆炸区域与指示器半径统一为 3.5。
- 二技能击退动作的目标上限改为前方范围查询的多目标，近端目标仍按距离缩放击退力度。
- 三技能的飞艇生命周期改为 14 秒，投弹周期为 1 秒，炸弹落地延迟为 650ms；后续仍需补齐每秒随机选敌和目标已损生命比例法术伤害的运行时验收。

1. **小乔大招单目标命中上限**：先核准正式服版本规则。现有 `adjust_damage_number` 只处理同目标伤害衰减，不会阻止超额命中；应新增明确的 hit-limit 状态/动作语义，不能把零伤害伪装成未命中。
2. **嬴政大招目标交互**：先完善目标碰撞类型、弹道穿透数、锁方向和重复命中验收，再按正式服目标规则调整配置。
3. **鲁班飞艇与赵云/廉颇位移验收**：以真实变换、位置和伤害/控制结果验证移动中碰撞、位移终点及召唤物结束行为。

## 发布检查

- 数据、Trigger source 与 module asset 同步；运行时聚合 JSON 不作为编辑入口。
- 扩展 PlanAction 时同步 action schema、生成清单、工具 schema/验证和相关单测；新触发器通过 Trigger Authoring 发布。
- 技能验收必须断言真实冷却、位置、伤害、命中数量或状态，不以 effect trace 作为唯一成功条件。
- 发布后运行受影响英雄 EditMode 验收、`TriggerAuthoringMobaMigration.CheckRuntimeBatch`、`python LubanConfig/Moba/export_pipeline.py --check-published` 及对应 .NET 冒烟测试。
